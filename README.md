# Avito → Telegram: монитор новых объявлений

[![Python](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/)
[![Telethon](https://img.shields.io/badge/Telethon-MTProto-2CA5E0)](https://docs.telethon.dev/)
[![Playwright](https://img.shields.io/badge/Playwright-Chromium-2EAD33)](https://playwright.dev/)
[![License: MIT](https://img.shields.io/badge/license-MIT-green)](LICENSE)

Telegram-бот, который принимает ссылку на **результаты поиска Авито**, запоминает уже существующие объявления и присылает в чат только новые — одним сообщением: фото + подпись + кнопки.

Карточка выглядит так:

```
📦 Xbox Series S, 512 ГБ
💳 Цена: 25 000 ₽
👤 Продавец: частное лицо (завершённых: 8)
⭐ Рейтинг: 5.0 - 462 отзыва
📝 Продаю бокс с двумя геймпадами, состояние отличное…

[✈️ Открыть на Авито]
[🚫 Заблокировать продавца]
```

Фотографии скачиваются во временную папку, отправляются в Telegram и **сразу удаляются**. На диске они не остаются, в базе не сохраняются. WebP/AVIF автоматически перекодируются в JPEG — иначе Telegram сохраняет их как стикер и не показывает подпись.

## Возможности

- Несколько поисков на один чат и несколько пользователей.
- Первый запуск не спамит старыми объявлениями: текущие объявления запоминаются.
- Фильтр по **реальному** времени публикации: бот присылает объявления за последние N часов (`AVITO_FRESH_HOURS`), даже если увидел их не сразу.
- Одно сообщение = один лот: фото + подпись (📦 / 💳 / 👤 / ⭐ / 📝) + две кнопки.
- Кнопка «🚫 Заблокировать продавца» скрывает все его объявления в этом чате.
- Продавец, рейтинг, число отзывов и полное описание подтягиваются из карточки объявления.
- Выдача читается из открытого браузера (Playwright/Chromium), поэтому JS-проверка Авито проходится штатно.
- Состояние и подписки хранятся в SQLite.
- При блокировке Авито бот не спамит ошибками: предупреждение не чаще раза в 6 часов.

## Почему Telethon, а не обычный Bot API

В этой сети `api.telegram.org` (HTTP Bot API) недоступен, а MTProto-соединения работают через прокси. Поэтому бот работает через **Telethon** (MTProto). Поддерживаются два варианта:

- `TELEGRAM_PROXY_URL=socks5://127.0.0.1:9050` — обычный SOCKS5/HTTP-прокси (например, локальный Tor); приоритетнее;
- `TELEGRAM_MT_PROXY=tg://proxy?server=...&port=...&secret=...` — MTProto-прокси одной строкой (или поля `TELEGRAM_MT_PROXY_SERVER/PORT/SECRET`).

Bot API сюда не подходит: MTProto-прокси не умеет проксировать HTTP.

## Tor на 127.0.0.1:9050

Если нужен локальный SOCKS5 на `9050`, запустите Tor (подойдёт `tor.exe` из Tor Browser):

```powershell
& "C:\Users\<user>\...\Tor Browser\...\Tor\tor.exe" -f Z:\Unkn0WnSCAN\data\tor\torrc
```

`torrc`:

```
SocksPort 9050
DataDirectory Z:\Unkn0WnSCAN\data\tor
GeoIPFile ...\TorBrowser\Tor\geoip
GeoIPv6File ...\TorBrowser\Tor\geoip6
```

Затем в `.env`:

```env
TELEGRAM_PROXY_URL=socks5://127.0.0.1:9050
AVITO_PROXY_URL=socks5h://127.0.0.1:9050
```

Telegram через Tor работает, но Avito обычно блокирует выходные узлы Tor и отдаёт `429`/`439` с проверкой. В этом случае оставьте Telegram на `9050`, а для Avito укажите отдельный мобильный/резидентный прокси в `AVITO_PROXY_URL`.

Для работы нужны `TELEGRAM_API_ID` / `TELEGRAM_API_HASH`. В `.env.example` стоят публичные ключи Telegram Desktop для быстрого старта. Для постоянной работы лучше получить собственные на [my.telegram.org](https://my.telegram.org) → API development tools.

## Быстрый старт (Windows)

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

3. Создайте `.env`:

```powershell
Copy-Item .env.example .env
notepad .env
```

Заполните:

```env
BOT_TOKEN=...
TELEGRAM_API_ID=2040
TELEGRAM_API_HASH=b18441a1ff607e10a989891a5462e627

TELEGRAM_MT_PROXY_SERVER=127.0.0.1
TELEGRAM_MT_PROXY_PORT=1443
TELEGRAM_MT_PROXY_SECRET=dd...
```

4. Убедитесь, что локальный MTProto-прокси запущен (порт `1443` слушается).
5. Запустите бота в отдельном окне консоли — просто откройте `run.bat`
   (или выполните `python bot.py`):

```powershell
.\run.bat
```

`run.bat` запускает бота в режиме обычной консоли: все логи видны в окне CMD,
браузер работает без окон (headless). Если нужно остановить — закройте окно
или нажмите `Ctrl+C`.

6. Напишите боту `/start` и пришлите ссылку на поиск Авито.

По умолчанию бот ищет **по всей России** (`AVITO_ALL_RUSSIA=true`): город из
ссылки отбрасывается, а в выдаче видны объявления из всех регионов. Чтобы
искать только по городу, поставьте `AVITO_ALL_RUSSIA=false`.

## Как пользоваться

1. Откройте Авито, задайте город, категорию, цену, запрос и другие фильтры.
2. Скопируйте ссылку из адресной строки браузера. Это должна быть страница **поиска**, а не отдельного объявления.
3. Отправьте ссылку боту или используйте `/add <ссылка>`.
4. Бот один раз прочитает текущую выдачу и запомнит её.
5. Дальше он проверяет поиск каждые 5 минут и присылает только новые объявления.

Команды:

- `/start` — инструкция.
- `/search <запрос>` — найти объявления прямо сейчас по слову (например, `/search iphone 13`).
- `/add <ссылка>` — добавить поиск.
- `/list` — список поисков, статус и кнопки удаления.
- `/del <номер>` — удалить поиск.
- `/check <номер>` — проверить сейчас, не дожидаясь интервала.
- `/retry` — сбросить паузу после блокировки Авито и проверить сейчас.
- `/help` — помощь.

Ссылку можно просто отправить сообщением, без команды. Текст без ссылки тоже
считается поисковым запросом: бот сразу пришлёт подходящие объявления.

## Фото

1. Бот получает URL фотографий из данных объявления.
2. Скачивает до 10 картинок в уникальную временную папку.
3. Отправляет их альбомом или одним фото.
4. Сразу удаляет временную папку целиком — и после успеха, и после ошибки.
5. Если фото не скачались, отправляет текстовую карточку.

## Про блокировки Авито

Авито защищается от автоматических запросов и отвечает `HTTP 439` клиентам, которые не проходят JavaScript-проверку (обычный `curl`/`requests`/`curl-cffi` её не проходит).

Поэтому по умолчанию парсер **ходит в Авито через настоящий Chromium** (Playwright). Браузер сам решает антибот-проверку, а данные берутся из уже отрисованной страницы (`AVITO_USE_BROWSER=true`).

Что нужно один раз установить:

```bash
pip install playwright
playwright install chromium
```

Настройки в `.env`:

```env
# true = грузить Авито через браузер (рекомендуется)
AVITO_USE_BROWSER=true
# true = без окна браузера; false = видимое окно (лучше проходит проверку)
AVITO_BROWSER_HEADLESS=false
# Постоянный профиль: куки и «прогрев» сохраняются между запусками
AVITO_BROWSER_PROFILE=data/browser_profile
```

Аккаунт и твой Cookie **не нужны** — используется анонимная браузерная сессия.

Если браузерный режим выключить, останется старый путь через `curl-cffi`. Тогда Авито часто отдаёт `403`, `429` или `439`, и нужен прокси:

```env
AVITO_PROXY_URL=http://user:password@host:port
# или
AVITO_PROXY_URL=socks5://user:password@host:port
```

Можно указать сразу несколько прокси — клиент **и браузер** будут ротировать их при блокировке:

```env
AVITO_PROXY_URLS=http://user:pass@host1:port,socks5://user:pass@host2:port
# или список в файле, по одному на строку
AVITO_PROXY_FILE=data/proxies.txt
```

Отдельный прокси только для Chromium (если нужно):

```env
AVITO_BROWSER_PROXY=socks5://user:password@host:port
```

Если прокси нет или они не помогают, после проверки IP бот **не долбит Авито**, а уходит на паузу. Пауза растёт: 10 → 20 → 40 → 80 → 120 минут (максимум 2 часа). Пока пауза активна, запросы не отправляются, а в лог пишется только отладочная строка. Проверку IP можно пройти вручную в открытом окне браузера — после паузы бот продолжит сам.

```env
# Перезапускать браузер на следующем прокси из списка при блокировке
AVITO_ROTATE_ON_BLOCK=true
# Первая пауза после блокировки, минуты (дальше удваивается)
AVITO_BLOCK_PAUSE_MINUTES=10
```

Важно: Tor и бесплатные/дата-центровые прокси Авито обычно блокирует (HTTP `439`). Для стабильной работы нужен резидентный или мобильный прокси.

`AVITO_COOKIE` по-прежнему поддерживается как необязательный запасной вариант, но для работы он больше не требуется. Не публикуйте `.env`: там токен бота и прокси.

### Как получить Cookie (необязательно)

Скрипт откроет Авито в браузере и сохранит готовый Cookie-заголовок:

```bash
pip install playwright
playwright install chromium
python get_cookie.py
```

После входа в браузере скрипт сохранит строку вида `SID=...; UNIQUE=...` в файл `data/avito_cookies.txt` и выведет её. Затем добавь её в `.env`:

```env
AVITO_COOKIE=SID=...; UNIQUE=...
```

Переменные окружения утилиты: `HEADLESS` (по умолчанию `false`), `COOKIE_OUT` (файл для сохранения, по умолчанию `data/avito_cookies.txt`), `COOKIE_TIMEOUT` (таймаут ожидания входа в секундах, по умолчанию `180`).

MTProto-прокси из `tg://...` помогает только Telegram, но не Авито.

## Docker

```bash
cp .env.example .env
# заполните BOT_TOKEN и параметры MTProto-прокси
docker compose up -d --build
docker compose logs -f
```

В Docker `127.0.0.1` — это сам контейнер. Если MTProto-прокси запущен на хосте, укажите `TELEGRAM_MT_PROXY_SERVER=host.docker.internal` (Windows/macOS) и разрешите прокси слушать не только loopback. На Linux проще `network_mode: host`.

## Как это работает внутри

- `avito.py` — загрузка страницы, извлечение карточек из отрендеренного DOM (и JSON-фолбэк), чтение времени публикации и данных продавца.
- `avito_browser.py` — один Chromium и одна переиспользуемая страница; картинки, шрифты и медиа не скачиваются, чтобы не нагружать систему.
- `monitor.py` — цикл проверки, фильтр свежести, отправка только unseen-объявлений, пропуск заблокированных продавцов.
- `formatter.py` — подпись к фото: название, цена, продавец, рейтинг, описание в цитате.
- `notifier.py` — скачивание и конвертация фото (WebP → JPEG), отправка через Telethon одним сообщением с кнопками и немедленная очистка.
- `storage.py` — SQLite: подписки, просмотренные ID, заблокированные продавцы.
- `bot.py` — Telethon-клиент, команды и inline-кнопки («заблокировать продавца»).

## Ограничения

- Нужна ссылка на поиск. Ссылка на одно объявление отклоняется.
- Как только в выдаче появляется новое объявление, оно уходит сразу (страница сама обновляется каждые ~20 сек). Отложенных сообщений «пришлю позже» больше нет.
- Если между проверками появилось больше `MAX_NEW_PER_CHECK` объявлений, остальные придут в следующем цикле.
- Для работы нужен доступ к `avito.ru`. При жёсткой блокировке IP без прокси бот не сможет получать данные.
- Сессия Telethon (`data/bot.session`) привязана к боту. Не удаляйте её при работающих подписках, иначе бот может не найти старые чаты до нового сообщения от них.
